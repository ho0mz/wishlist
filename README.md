# Wishlist

Веб-приложение для ведения списков желаний. Учебный проект по работе с DOM: вся страница строится и обновляется нативными средствами браузера, без библиотек и фреймворков.

**Рабочая версия:** _ссылка_

## Что делает проект

- создаёт несколько списков желаний (день рождения, Новый год и т. д.);
- хранит карточки желаний: название, цена, ссылка, приоритет, категория, статус;
- ищет, фильтрует и сортирует желания;
- показывает статистику по списку;
- сохраняет данные в браузере (`localStorage`).

## Технологии

- HTML5, CSS3
- JavaScript (ES-модули, без библиотек и фреймворков)
- DOM API: `querySelector`, `createElement`, `appendChild`, `addEventListener`, `classList`, `dataset`, `textContent`
- `localStorage` для хранения данных
- GitHub Pages для публикации

## Как запустить локально

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/ho0mz/wishlist.git
   cd wishlist
   ```
2. Запустите локальный сервер (ES-модули не работают при открытии файла напрямую):
   - в VS Code: расширение **Live Server** → «Open with Live Server»;
   - или в терминале: `python -m http.server 8000`, затем откройте `http://localhost:8000`.
